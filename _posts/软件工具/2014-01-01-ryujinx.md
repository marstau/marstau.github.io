## Installation[More](https://ryujinx.app/)

#### 安装密钥（Keys）和固件（Firmware）

打开Ryujinx模拟器，在菜单栏点击 File -> Open Ryujinx Folder，这会打开模拟器的数据文件夹。
进入其中的 system 子文件夹。
将下载好的 prod.keys 文件复制到这个 system 文件夹中。

回到Ryujinx界面，点击菜单栏的 Tools -> Install Firmware -> Install a firmware from XCI or ZIP。
在弹出的窗口中，选择你下载好的Switch固件压缩包（如 Firmware 16.0.2.zip），点击打开即可开始安装。
完成这两步后，模拟器的核心配置就完成了。
